# Лабораторна робота №1
## Імплементація блогу «Мої 3 найкращі міста світу»

**Дисципліна:** WEB-програмування

### Мета роботи
Набути практичних навичок створення багатосторінкового вебсайту за допомогою HTML, використання семантичної розмітки, організації файлової структури проєкту, роботи з Git і GitHub та публікації сайту за допомогою GitHub Pages.

### Опис проєкту
Проєкт являє собою статичний вебсайт на тему «Мої 3 найкращі міста світу». На сайті представлені три міста: Київ, Париж і Токіо.

Кожне місто має окрему HTML-сторінку з описом, цікавими фактами, визначними місцями та особистою оцінкою. На головній сторінці розміщена навігація між сторінками. Також створена форма, за допомогою якої можна запропонувати місто для наступного рейтингу.

### Використані технології
- HTML5 — створення структури вебсторінок.
- Git — контроль версій проєкту.
- GitHub — зберігання вихідного коду.
- GitHub Pages — публікація вебсайту в інтернеті.

### Структура проєкту
```text
my-best-cities/

├── city-tokyo.html
├── form.html
├── images/
│   ├── kyiv.jpg
│   ├── paris.jpg
│   └── tokyo.jpg
└── README.md
```

### Функціональні можливості
1. Перегляд головної сторінки з інформацією про три міста.
2. Перехід до окремої сторінки кожного міста.
3. Навігація між сторінками сайту.
4. Перегляд описів, цікавих фактів і визначних місць.
5. Перехід до зовнішніх інформаційних ресурсів.
6. Заповнення HTML-форми для пропозиції нового міста.
7. Перевірка обов'язкових полів форми засобами браузера.

### Висновок
Під час виконання лабораторної роботи створено багатосторінковий статичний вебсайт із використанням HTML5. Закріплено навички створення HTML-документів, застосування семантичних елементів, організації навігації між сторінками, підключення зображень і створення HTML-форми. Також проєкт підготовлено до розміщення в репозиторії GitHub і публікації за допомогою GitHub Pages.
